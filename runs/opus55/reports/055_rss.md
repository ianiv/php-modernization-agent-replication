It produced the expected values with no warnings, notices or deprecations.

**Fixes for PHP 8 breakage:**
- **Constructors:** `MagpieRSS` and `RSSCache` used PHP 4-style constructors, which PHP 8 no longer runs, so `new MagpieRSS($src)` would not have parsed anything. Both now use `__construct()`. I kept `MagpieRSS()` and `RSSCache()` as methods that call `__construct()`, so code that calls them directly still works.
- **`split()`:** it was removed from PHP; it's now `explode(':', …, 2)`. The separator is a plain character, so the result is the same.
- **`map_attrs`:** it's now `public static`. It's called as a static callback (`['MagpieRSS','map_attrs']`), which throws an Error in PHP 8 for a non-static method.
- **Parser check:** `xml_parser_create()` now returns an object rather than a resource, so the old `is_resource()` test would always report failure. It now also accepts an `XMLParser` object.
- **XML handlers:** these are now first-class callables (`$this->feed_start_element(...)`) instead of `xml_set_object()` plus method-name strings. I removed the by-reference `&$attrs` parameter, which the XML extension can't pass and which triggers a warning.
- **Dynamic properties:** `fetch_rss()` and `_response_to_rss()` attach `etag`, `last_modified` and `from_cache` to the object at runtime. I added `#[\AllowDynamicProperties]` to both classes. Declaring those properties instead would have changed what `isset()`, serialization and `get_object_vars()` return.
- **`parse_w3cdtf()`:** the regex parts are cast to `(int)` before `gmmktime()`, because a missing seconds value is an empty string, which throws a TypeError in PHP 8. Optional parts that didn't match default to `''`.

**Modernization:** `var` became `public`, `array()` became `[]`, and `list()` became `[...]`. I added `(string)` casts where a null would now raise a deprecation, and `?? null` / `?? ''` on array keys that may be missing (`version`, `rel`, `href`, `tagline`, `description`, `stack[0]`).

**Deliberate behavior changes:** none. The `??` defaults give the same values PHP 5 used for a missing key; the only difference is that PHP 8 no longer logs a warning for them.
